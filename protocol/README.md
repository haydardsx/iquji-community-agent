# IQuji Community Agent Wire

[简体中文](README.zh-CN.md)

Rust types and validators for agent requests, events, model configuration and process supervision.

```toml
[dependencies]
iquji-community-agent-wire = "=0.2.0"
```

The Rust module is `iquji_agent_wire`. Use `decode_turn_request` to parse incoming requests. Released under the [MIT License](LICENSE).
